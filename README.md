# EditorAL

A native text and code editor for macOS 14 or later, with project folders, tabs, syntax highlighting, Terminal / Log coloring, line comments, smart indentation, matching-bracket navigation, regex find/replace, and text encoding controls.

[Download the latest release](https://github.com/ngzhenghui94/EditorAL/releases/latest)

Unzip the download and move **EditorAL.app** into **Applications**. Releases support Apple Silicon and Intel Macs, are signed with Developer ID, and are notarized by Apple.

Or install through Homebrew:

```sh
brew install --cask ngzhenghui94/tap/editoral
```

Use **EditorAL → Check for Updates…** to check for a new version. Automatic update checks are optional. Updates use Sparkle and signed downloads.

This repository hosts release binaries and the update feed. Source code is not published here.
