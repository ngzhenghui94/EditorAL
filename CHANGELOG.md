# Release notes

## EditorAL 1.2

- Add a Terminal / Log language mode for `.log` files and pasted output. It highlights log levels and status words, timestamps, IPv4/IPv6 addresses, URLs, email addresses, paths, common shell commands/options/variables, and added/removed diff lines. Syntax colors do not change saved file content.

[Download EditorAL 1.2](https://github.com/ngzhenghui94/EditorAL/releases/tag/v1.2)

## EditorAL 1.1

- Recover edited files and untitled notes after an unexpected exit. Recovery copies preserve text and encoding without overwriting the original file. The last keystrokes before a crash may not have been copied yet.
- Show a live Markdown preview with Shift–Command–P. Supports headings, emphasis, lists, tasks, quotes, code and basic tables. Images show alternative text; raw HTML remains text.
- Browse local saved-version history and restore earlier text with undo support.
- Choose System, Dracula, Monokai or Nord syntax colors.
- Save new notes in Documents by default.
- Check for signed updates from the EditorAL menu.

Requires macOS 14 or later. The download supports Apple Silicon and Intel Macs, is Developer ID signed, and is notarized by Apple.

[Download EditorAL 1.1](https://github.com/ngzhenghui94/EditorAL/releases/tag/v1.1)
